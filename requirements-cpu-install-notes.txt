1. Create and activate the virtual environment.

2. Install CPU-only Torch first:
pip install --index-url https://download.pytorch.org/whl/cpu torch==2.11.0+cpu torchvision==0.26.0 torchaudio==2.11.0+cpu

3. Install the rest of the project requirements:
pip install -r requirements.txt

4. If transparent-background tries to reinstall Torch or GPU packages, install it separately with:
pip install --no-deps transparent-background==1.3.4
